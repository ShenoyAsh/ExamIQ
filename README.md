
  # 🎓 ExamIQ: AI-Powered Exam Analyzer & Study Planner

[![Build Status](https://img.shields.io/badge/build-passing-brightgreen.svg)](https://github.com/ShenoyAsh/ExamIQ)
[![Tech Stack](https://img.shields.io/badge/tech-React%20%7C%20Vite%20%7C%20OpenAI-blue.svg)](https://github.com/ShenoyAsh/ExamIQ)

**ExamIQ** is a state-of-the-art AI application designed to help students prepare strategically for their exams. By analyzing years of past question papers and cross-referencing them with the official syllabus, ExamIQ identifies high-yield topics, predicts question patterns, and generates a personalized, prioritized study plan.

## ✨ Key Features

- 📄 **Multi-Paper Analysis**: Upload multiple past question papers (PDF or images) for comprehensive trend analysis.
- 🤖 **AI Pattern Recognition**: Automatically extract topics, identify question frequency, and detect phrasing styles using OpenAI GPT-4o.
- 🎯 **Syllabus Mapping**: Map extracted topics against the official syllabus to identify coverage gaps and focus areas.
- 📈 **Visual Analytics Dashboard**: Interactive charts and heatmaps visualizing topic distribution and difficulty trends.
- 📅 **Smart Study Planner**: Auto-generate a study schedule that prioritizes high-impact topics based on historical data.
- 🏆 **Topic Importance Scoring**: Rank topics by predicted exam weight to optimize study efficiency.

## 🛠️ Tech Stack

- **Frontend**: [React 18](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [Shadcn UI](https://ui.shadcn.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **AI Integration**: [OpenAI API](https://openai.com/api/) (GPT-4o-mini)
- **PDF Processing**: [PDF.js](https://mozilla.github.io/pdf.js/)
- **Data Visualization**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm
- OpenAI API Key

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ShenoyAsh/ExamIQ.git
   cd ExamIQ
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up environment variables**:
   Create a `.env` file in the root directory and add your OpenAI API key:
   ```env
   VITE_OPENAI_API_KEY=your_api_key_here
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

5. **Build for production**:
   ```bash
   npm run build
   ```
